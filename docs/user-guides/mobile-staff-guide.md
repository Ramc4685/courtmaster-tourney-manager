# Mobile Staff Guide for CourtMaster Tournament Manager

## Overview

This guide covers tablet and smartphone workflows for tournament staff including front desk personnel, scorekeepers, and court officials. CourtMaster is designed for offline-first operation, ensuring smooth tournament operations even with poor internet connectivity.

## Mobile Device Setup

### Recommended Device Specifications

#### Tablets (Primary Recommendation)
- **Screen Size**: 10-12 inches for optimal visibility
- **Operating System**: iOS 14+ or Android 10+
- **Storage**: Minimum 32GB available space
- **RAM**: 4GB or higher for smooth performance
- **Battery**: Minimum 8-hour battery life
- **Connectivity**: Wi-Fi and cellular data capability

#### Smartphones (Backup/Secondary)
- **Screen Size**: 6+ inches recommended
- **Operating System**: iOS 14+ or Android 10+
- **Storage**: Minimum 16GB available space
- **Battery**: Power bank recommended for extended use

### PWA Installation Process

#### For iOS Devices (Safari)
1. Open Safari and navigate to the tournament URL
2. Tap the **Share** button (square with arrow)
3. Scroll down and tap **"Add to Home Screen"**
4. Customize the app name if desired
5. Tap **"Add"** to complete installation

#### For Android Devices (Chrome)
1. Open Chrome and navigate to the tournament URL
2. Tap the **Menu** button (three dots)
3. Select **"Add to Home Screen"**
4. Customize the app name if desired
5. Tap **"Add"** to complete installation

#### For Windows Tablets (Edge)
1. Open Microsoft Edge and navigate to the tournament URL
2. Click the **Settings** menu (three dots)
3. Select **"Apps"** → **"Install this site as an app"**
4. Follow the installation prompts

### Initial App Configuration

#### Login and Authentication
1. Launch the installed PWA
2. Enter your staff credentials provided by tournament organizer
3. Verify your role assignment (Front Desk, Scorekeeper, Court Official)
4. Test offline functionality by briefly disconnecting from internet

#### Device-Specific Settings
- **Notification Permissions**: Enable for match updates and alerts
- **Location Services**: Allow for court assignment features
- **Screen Brightness**: Set to maximum for outdoor visibility
- **Screen Timeout**: Extend to prevent auto-lock during matches
- **Do Not Disturb**: Configure to allow tournament notifications only

## Front Desk Operations

### Team Check-in Process

#### Standard Check-in Workflow
1. **Access Check-in Interface**
   - Open **Registration** → **Team Check-in**
   - Search for team by name or confirmation number
   - Verify team roster and player details

2. **Player Verification**
   - Check photo ID against registration
   - Verify player eligibility and skill level
   - Confirm emergency contact information
   - Note any special requirements or accommodations

3. **Document Collection**
   - **Waivers**: Ensure all players have signed
   - **Medical Forms**: Collect any required medical information
   - **Payment**: Verify fee payment status
   - **Registration Changes**: Process last-minute roster updates

4. **Complete Check-in**
   - Mark team as "Checked In" in system
   - Print/provide tournament materials:
     - Schedule and bracket information
     - Venue map and court locations
     - Emergency procedures and contacts
     - Tournament rules and regulations

#### Handling Special Situations

##### Late Arrivals
- **After Registration Deadline**: Contact tournament director
- **Partial Team**: Allow check-in with minimum players
- **No-show Teams**: Mark as withdrawn, update brackets automatically
- **Emergency Substitutions**: Follow emergency player addition procedures

##### Payment Issues
- **Outstanding Fees**: Hold registration until payment received
- **Refund Requests**: Direct to tournament director
- **Payment Method Issues**: Accept alternative payment methods as authorized

##### Documentation Problems
- **Missing Waivers**: Have backup forms available for on-site signing
- **Expired Medical Forms**: Allow conditional participation with updated forms
- **ID Verification Issues**: Escalate to tournament director

### Tournament Information Desk

#### Common Inquiries and Responses

##### Schedule Questions
- **"When is my next match?"**: Use player search to find upcoming matches
- **"Which court am I on?"**: Check court assignments in real-time
- **"How long until my match?"**: Calculate based on current match progress
- **"Can I change my match time?"**: Direct to tournament director

##### Facility Information
- **Restroom Locations**: Point to venue map
- **Food and Beverages**: Provide concession stand information
- **Parking**: Share parking map and any time restrictions
- **Lost and Found**: Maintain lost items log

##### Rules and Regulations
- **Scoring Rules**: Provide quick reference card
- **Time Limits**: Explain warm-up and break times
- **Equipment Rules**: Clarify what equipment is/isn't allowed
- **Conduct Policies**: Address sportsmanship expectations

### Real-time Communication

#### Staff Coordination
- **Match Delays**: Immediately notify affected teams and officials
- **Court Changes**: Update all relevant parties
- **Emergency Situations**: Follow established communication protocols
- **Schedule Updates**: Push notifications to registered participants

#### Participant Updates
- **Mass Announcements**: Use public address system integration
- **Individual Notifications**: Send direct messages to specific teams
- **Social Media Updates**: Post tournament progress if authorized
- **Family/Spectator Communication**: Provide viewing schedule updates

## Scorekeeper Workflows

### Pre-Match Setup

#### Court Assignment and Setup
1. **Receive Match Assignment**
   - Check assigned court number and match details
   - Verify equipment setup (nets, scoring displays, seating)
   - Test mobile scoring interface connectivity

2. **Player Verification**
   - Confirm team rosters match tournament registration
   - Check for any last-minute player substitutions
   - Verify player eligibility if questions arise

3. **Equipment Check**
   - **Scoring Display**: Ensure visibility from all court positions
   - **Backup Scoring**: Have paper scoresheet ready
   - **Communication**: Test radio or messaging with tournament desk
   - **Emergency Supplies**: First aid kit location, incident report forms

### Live Scoring Operations

#### Mobile Scoring Interface

##### Match Start Procedure
1. **Open Scoring App**
   - Navigate to **Live Scoring** → **Active Matches**
   - Select your assigned match
   - Verify team names and player rosters

2. **Pre-Match Setup**
   - Confirm starting server/receiver
   - Set initial game settings (sets to win, points to win)
   - Test score display functionality
   - Start match timer if required

##### During Match Scoring

###### Point-by-Point Scoring
- **Tap Team Buttons**: Award points with single taps
- **Undo Function**: Use undo button for scoring errors
- **Service Changes**: System automatically tracks service rotation
- **Set Completion**: Automatic detection when set/game is won

###### Common Scoring Scenarios
- **Service Faults**: Award point to receiving team
- **Let Serves**: Replay point, no score change
- **Disputed Points**: Stop play, consult rules official
- **Equipment Issues**: Pause timer, note delay reason

##### Set and Match Management
- **Set Completion**:
  - Confirm set winner
  - Allow players appropriate rest time
  - Reset score for next set
  - Update set score display

- **Match Completion**:
  - Confirm final result with both teams
  - Get captain signatures if required
  - Submit final scores to tournament system
  - Clear court for next match

#### Backup and Manual Scoring

##### Paper Scoresheet Procedures
When mobile scoring is unavailable:
1. Use official paper scoresheets as backup
2. Record all points, service changes, and timeouts
3. Get both team captains to sign completed scoresheet
4. Enter scores into mobile system when connectivity returns

##### Score Verification Process
- **Mid-Match Checks**: Verify scores with players periodically
- **Set Completion**: Confirm final set scores before proceeding
- **Match End**: Get acknowledgment from both teams
- **Discrepancy Resolution**: Stop play and resolve immediately

### Post-Match Procedures

#### Result Recording and Verification
1. **Final Score Confirmation**
   - Display final scores for both teams to verify
   - Get verbal confirmation from team captains
   - Note any protests or disputes for tournament director review

2. **System Updates**
   - Submit match results immediately
   - Verify automatic bracket updates
   - Check for next match assignments
   - Update court availability status

3. **Equipment and Court Reset**
   - Reset scoring displays to 0-0
   - Prepare court for next match
   - Report any equipment issues to maintenance
   - Update court status to "Available" or "Next Match Ready"

## Court Official Procedures

### Pre-Match Official Duties

#### Court Inspection and Setup
- **Net Height**: Verify correct height for sport/division
- **Court Lines**: Check visibility and accuracy of boundary lines
- **Playing Surface**: Ensure safe, clean playing conditions
- **Equipment**: Verify balls/shuttlecocks are regulation quality

#### Player and Team Coordination
- **Pre-Match Conference**: Brief players on rules and procedures
- **Warm-up Management**: Enforce warm-up time limits
- **Equipment Check**: Verify player equipment meets regulations
- **Substitution Rules**: Explain substitution procedures if applicable

### During Match Officiating

#### Using Mobile Official Interface

##### Match Control Functions
- **Score Tracking**: Monitor scorekeeper accuracy
- **Time Management**: Track set breaks and timeout usage
- **Rule Enforcement**: Access quick reference for rules questions
- **Incident Reporting**: Document any disputes or injuries

##### Real-time Communication
- **Tournament Desk**: Report delays or issues immediately
- **Medical Staff**: Quick access to medical alert functions
- **Security**: Direct contact for behavioral issues
- **Technical Support**: Fast response for equipment problems

#### Common Officiating Scenarios

##### Rule Disputes
1. **Stop Play**: Immediately halt game action
2. **Consult Resources**: Use mobile rule reference or contact head official
3. **Make Decision**: Render fair and final decision
4. **Resume Play**: Restart from appropriate point
5. **Document**: Record dispute details for tournament records

##### Equipment Failures
- **Immediate Safety**: Ensure player safety first
- **Assess Situation**: Determine if play can continue
- **Contact Maintenance**: Report equipment issues
- **Alternative Solutions**: Move to backup court if necessary

##### Medical Situations
- **Stop Play**: Immediate halt for any injury
- **Assess Severity**: Determine if medical assistance needed
- **Contact Medical**: Alert first aid personnel if required
- **Documentation**: Complete incident report
- **Resume Decision**: Determine if player can continue

### Post-Match Official Duties

#### Result Verification and Reporting
- **Score Confirmation**: Verify final scores with scorekeeper
- **Rule Compliance**: Confirm match was played according to regulations
- **Incident Reports**: Complete any required incident documentation
- **Next Assignment**: Check for additional officiating duties

## Offline Mode Operations

### Understanding Offline Functionality

#### What Works Offline
- **Live Scoring**: All scoring functions continue to operate
- **Team Check-in**: Access to pre-downloaded team rosters
- **Schedule Viewing**: Previously cached schedule information
- **Basic Communication**: Internal staff messaging
- **Data Storage**: All actions saved locally for later sync

#### What Requires Internet Connection
- **Real-time Updates**: Live bracket updates across devices
- **New Team Registration**: Adding teams not previously cached
- **External Communication**: Email notifications and social media
- **Payment Processing**: Credit card and online payment systems

### Offline Mode Best Practices

#### Preparation for Offline Operation
1. **Pre-Download Data**
   - Sync all tournament data before event starts
   - Download team rosters, schedules, and brackets
   - Cache venue maps and emergency information
   - Store staff contact information locally

2. **Battery Management**
   - Charge all devices to 100% before tournament start
   - Have backup power banks available
   - Reduce screen brightness to conserve battery
   - Close unnecessary apps running in background

#### During Offline Operation

##### Data Entry Protocols
- **Continue Normal Operations**: All core functions work offline
- **Document Critical Changes**: Note any manual adjustments made
- **Regular Sync Attempts**: Check for connectivity periodically
- **Backup Documentation**: Maintain paper records as backup

##### Communication Procedures
- **Staff Coordination**: Use internal messaging when available
- **Radio Backup**: Have two-way radios for critical communication
- **Runner System**: Designate staff for physical message delivery
- **Central Coordination**: Maintain single point of truth for schedule changes

#### Returning Online

##### Sync Procedures
1. **Automatic Sync**: Allow system to automatically upload cached data
2. **Conflict Resolution**: Review any data conflicts and resolve
3. **Verify Updates**: Confirm all changes properly synchronized
4. **Broadcast Updates**: Send any delayed notifications to participants

## Quick Actions and Emergency Procedures

### Critical Quick Actions

#### Medical Emergency Response
1. **Immediate Actions**
   - Tap **Emergency** button in app
   - Call for medical assistance
   - Clear area around injured person
   - Document incident details

2. **Information Gathering**
   - Player name and team
   - Nature of injury
   - Time of incident
   - Witnesses present

3. **Follow-up**
   - Complete incident report
   - Notify tournament director
   - Coordinate with medical personnel
   - Update player/team status

#### Equipment Emergency
1. **Safety First**: Ensure no safety hazards exist
2. **Quick Assessment**: Determine if issue affects play
3. **Contact Maintenance**: Report problem immediately
4. **Alternative Planning**: Identify backup solutions
5. **Communication**: Notify affected teams and staff

#### Weather Emergency (Outdoor Venues)
1. **Monitor Conditions**: Watch for dangerous weather
2. **Safety Protocol**: Move people to safe areas
3. **Communication**: Announce delays or cancellations
4. **Documentation**: Record weather-related delays
5. **Recovery Planning**: Plan for resumption of play

### Communication Emergency Procedures

#### System Failure
1. **Switch to Backup**: Use paper systems immediately
2. **Document Everything**: Record all actions taken
3. **Contact IT Support**: Report technical issues
4. **Inform Participants**: Announce any delays
5. **Continue Operations**: Don't stop tournament unnecessarily

#### Staff Communication Breakdown
1. **Establish Runner System**: Use staff for message delivery
2. **Central Command**: Create single information hub
3. **Regular Check-ins**: Schedule periodic staff updates
4. **Priority Messages**: Focus on critical information only
5. **Restore Communications**: Work to fix systems quickly

## Troubleshooting Mobile Issues

### Common Technical Problems

#### App Performance Issues

##### Slow Response Times
**Symptoms**: App laggy, delayed button responses
**Solutions**:
1. Close other apps running in background
2. Restart the tournament app
3. Restart the device if necessary
4. Check available storage space

##### Freezing or Crashes
**Symptoms**: App stops responding, unexpected closures
**Solutions**:
1. Force-close app and restart
2. Check for app updates
3. Restart device
4. Clear app cache if possible
5. Reinstall app as last resort

#### Connectivity Problems

##### Wi-Fi Connection Issues
**Symptoms**: Can't connect to venue Wi-Fi
**Solutions**:
1. Verify Wi-Fi password with venue staff
2. Try connecting to different network
3. Reset network settings on device
4. Switch to cellular data if available
5. Use offline mode if connection fails

##### Slow Data Transfer
**Symptoms**: Long delays when submitting scores
**Solutions**:
1. Check signal strength indicator
2. Move closer to Wi-Fi access point
3. Switch between Wi-Fi and cellular
4. Use offline mode and sync later
5. Contact IT support for network issues

#### Screen and Display Problems

##### Screen Visibility Issues
**Symptoms**: Can't see screen in bright light
**Solutions**:
1. Increase screen brightness to maximum
2. Find shaded area for device use
3. Use device hood or screen protector
4. Adjust viewing angle
5. Switch to device with better screen

##### Touch Sensitivity Problems
**Symptoms**: Touch responses not registering
**Solutions**:
1. Clean screen with microfiber cloth
2. Remove screen protector if interfering
3. Ensure hands are clean and dry
4. Use stylus if available
5. Restart device if problem persists

### Device Management

#### Battery Conservation
- **Reduce Brightness**: Lower screen brightness when possible
- **Close Apps**: Keep only essential apps running

2. **Multiple Devices**: Use redundant data entry

4. **Cloud Sync**: Enable automatic cloud backup
5. **Recovery Procedures**: Know how to restore data
